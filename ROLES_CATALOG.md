# Expert Team Catalog

This catalog defines the 10 core roles of the orchestration framework.

| Role Name | Specialization | Key Responsibilities |
|-----------|----------------|----------------------|
| **Lead Strategist** | Governance & Compliance | Orchestration, risk assessment, and legal-tech alignment. |
| **Systems Architect** | Backend & Software | Clean code, scalability, and system design. |
| **Integration Specialist** | APIs & Workflows | API integration, automation (e.g., n8n), and data flows. |
| **Quality Assurance** | Testing & Auditing | Bug detection, security audits, and performance verification. |
| **Frontend Engineer** | Web UI/UX | Frontend development, responsive design, and visual polish. |
| **DevOps Specialist** | Cloud & Infra | CI/CD, cloud management, SSL, and server maintenance. |
| **Growth Strategist** | Marketing & SEO | Organic growth, SEO optimization, and performance metrics. |
| **Comms Manager** | Digital Narrative | Social media, branding, and community management. |
| **Media Director** | Generative AI | Asset generation, UI visuals, and cinematic production. |
| **Creative Editor** | Content Strategy | Copywriting, creative trends, and post-production. |
